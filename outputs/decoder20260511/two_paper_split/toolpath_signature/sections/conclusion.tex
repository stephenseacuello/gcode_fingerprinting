\section{Conclusions}\label{sec:conclusion}

This paper introduced air-cut referencing with temporal binning as a methodology for extracting toolpath fingerprints from CNC sensor data. We evaluated four signal isolation methods across three classifiers for three-class toolpath classification (adaptive clearing, facing, pocketing) on a dataset of 51 active-cutting and 55 air-cutting runs from a desktop CNC mill.

The key findings are:

\begin{enumerate}
    \item \textbf{Task difficulty context.} Trivial baseline analysis reveals that the three toolpath types are separable from program metadata alone (G-code line range: 100\%, mean position: 98\%). This contextualizes the high sensor-based accuracy and underscores that the primary contribution is methodological rather than accuracy-driven.

    \item \textbf{Air-cut referencing provides genuine, confound-independent benefit.} With all position-confounded channels (magnetometers, color, pressure, proximity) excluded, raw RF drops to 96.7\% while the subtracted and ratio methods maintain 100\% accuracy and z-score remains near-perfect at 99.0\%. The referencing benefit is therefore not an artifact of the magnetometer position-encoding confound. The Friedman test ($p < 10^{-6}$) confirms statistical significance, and noise robustness analysis shows referenced features maintain accuracy up to $1.0\times$ noise.

    \item \textbf{Process dynamics are recoverable once position is controlled.} On a damaged-spindle detection task (air-cut runs with one drive band removed, same toolpath strategies, so workspace position is held constant), Random Forest reaches 98.5\% accuracy, and the discriminative importance shifts from the magnetometer to the accelerometer and acoustic-RMS channels. Because the comparison couples spindle condition with cutting engagement, it demonstrates process-dynamics detection rather than validated tool-condition monitoring. Air-cut referencing is neutral on this task, consistent with the causal model, under which referencing helps only when a position confound is present.

    \item \textbf{Temporal structure is informative.} Temporal binning (20 bins) outperforms whole-run summary statistics (100\% vs.\ 98\%), and produces interpretable fingerprint visualizations that reveal toolpath-specific sensor dynamics.

    \item \textbf{Minimal sensor requirements.} A single bed-mounted IMU achieves 100\% accuracy with 238 features. Only 5 training runs per class suffice for 96.4\% accuracy.

    \item \textbf{Competitive with modern methods.} ROCKET-style random convolutional features achieve comparable accuracy (98--100\%), confirming the task's accessibility and showing that the interpretable temporal-binning approach does not sacrifice performance.
\end{enumerate}

One limitation is that the air-cut and active-cutting data used different CAM-generated G-code programs, preventing direct G-code-aligned signal subtraction. The temporal binning approach compensates for this, but future data collection should use identical programs.

Future work will focus on: (1)~within-toolpath-type parameter discrimination (e.g., different stepovers), where trivial baselines cannot help and air-cut referencing should provide greater benefit; (2)~cross-machine validation to test transferability of referenced fingerprints; (3)~higher-rate data acquisition to enable frequency-domain features; and (4)~the deconfounded damage comparison --- damaged-spindle air-cuts against normal air-cuts of the same programs --- to separate spindle condition from cutting engagement (Section~\ref{sec:damage}).
