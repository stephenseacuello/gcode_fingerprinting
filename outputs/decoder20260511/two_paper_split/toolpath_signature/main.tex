% Abstract
\abstract{We propose air-cut referencing, a methodology for isolating toolpath-specific sensor signatures from CNC machining data by normalizing active-cutting measurements against air-cut (no-load) baselines. Using temporal binning to align program phases, we extract statistical features and evaluate four signal isolation methods---raw, mean-subtracted, ratio-normalized, and z-score---for three-class toolpath classification (adaptive clearing, facing, pocketing) with six Arduino Nano 33 BLE Sense Lite IMU modules (LSM9DS1) and four Hall-effect current sensors. Physical interpretation reveals that the dominant discriminative features are magnetometer channels encoding workspace position rather than cutting dynamics. Critically, when all position-confounded channels are excluded (784 features), raw features degrade to 96.7\% (minimum fold 81.8\% over 100 repeated CV evaluations) while the subtracted and ratio methods maintain perfect 100\% accuracy and z-score remains near-perfect (99.0\%, minimum 90\%)---a smaller but genuine, confound-independent benefit. On a position-controlled damaged-tool detection task (the same G-code programs run with a damaged tool; 51 normal vs.\ 14 damaged runs), accuracy reaches 98.5\% (balanced accuracy 0.99) and the discriminative signal shifts decisively from the magnetometer (0.1\% of importance) to the accelerometer and acoustic-RMS channels (74\% combined), confirming that the sensors capture genuine process dynamics once workspace position is held constant. Cross-condition transfer (37\% accuracy, near chance) confirms that air and active conditions produce fundamentally different feature distributions. Comprehensive ablation shows a single bed-mounted IMU suffices, 5 training runs per class achieve 96\%, and referenced features resist additive noise up to $1.0\times$ the feature standard deviation. These results establish air-cut referencing as a robust normalization strategy for CNC sensor data, while the physical interpretation analysis provides a template for distinguishing position-encoding confounds from process-relevant sensor signals.}
